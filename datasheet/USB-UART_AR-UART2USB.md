# AR-UART2USB 매뉴얼 (Manual Ver 1.5)

> 출처: `USB-UART_AR-UART2USB.pdf` — Ahramsoft (www.ahramsoft.com)

## 1. 모델 이름
AR-UART2USB

## 2. 용도
MCU의 TX, RX 신호를 USB 신호로 상호 변환하여, 시리얼 포트가 없는 PC에서 USB 포트로 **가상 시리얼 포트(COM)** 를 사용할 수 있게 한다. (MAX-232 불필요)

## 3. 제품 사양
| 항목 | 내용 |
|---|---|
| 변환 칩 | Silicon Labs **CP2102** (드라이버 설치 필요) |
| 대상 MCU 전원 | 3.3V ~ 5.5V 전원을 쓰는 CPU의 TX/RX 신호 |
| 과전류 보호 | Fuse 역할의 1Ω 저항(2012 사이즈) — 파손 시 교체하면 재사용 가능 |
| 케이블 | 200mm, 4핀 Double 하네스 커넥터 제공 (별도 구입 불필요) |
| 표시 | 전원 RED LED |
| 보조 출력 | 3.3V 출력 핀 (최대 100mA) |
| USB 커넥터 | Mini USB, DIP 타입 커넥터로 충격에 의한 파손 강화 |

## 4. 제품 외관 (부품 위치)
- **Mini USB 커넥터** — DIP 타입으로 고정력 강화
- **1Ω 저항 (FUSE)** — 과전류 시 끊어져 USB 포트/장치 보호
- **전원 LED**
- **3.3V 출력 핀** — 3.3V 장치에 연결 (최대 100mA)
- **CP2102** — USB ↔ UART 변환 IC
- **4핀 하네스 커넥터** — 2.54mm 피치, 핀 순서: `5V / TX / RX / G`

## 5. 사용 방법 (케이블 색상별 연결)
| 선 색 | 신호 | 연결 |
|---|---|---|
| 적색 | 5V | 5V 출력 |
| 파랑 | TX (출력) | **MCU의 RX 핀**에 연결 |
| 초록 | RX (입력) | **MCU의 TX 핀**에 연결 |
| 검정 | GND | GND |

> TX ↔ RX는 서로 교차 연결한다.

## 6. 제품 구성
1. 본체 1개
2. Double type 4핀 하네스 커넥터 1개 (2.54mm)
