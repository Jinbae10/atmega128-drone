# Drone V4 Optimized (`v4_opt`) 전면 재설계 문서

- **프로젝트 경로**: `BLDC/v4_opt/drone_v4_opt.kicad_pro` (기존 `BLDC/v4/` 프로젝트는 원본 보존)
- **최종 보드 크기**: **`64.0 × 80.0 mm` (`5,120 mm²`)**
  - 최초 V4 (`93.6 × 84.1 mm`, `7,872 mm²`) 대비 **면적 35.0% 축소** (가로 `-29.6 mm`, 세로 `-4.1 mm`)
  - 직전 축소 V4 (`75.6 × 84.1 mm`, `6,358 mm²`) 대비 **면적 19.5% 추가 축소**
- **마운팅 홀 규격**: 4모서리 대칭 M2 홀 (`57.0 × 73.0 mm` 피치, 외곽선 마진 `3.5 mm`)
- **작성 일시**: 2026-11-18

## 1. 핵심 설계 최적화 전략

1. **`U2` 소켓 하부 공간 활용 (기계적 안전 확보)**
   - `AT128A-70B (U2)`는 `8.5 mm` 높이 암헤더 + `2.5 mm` 수헤더(`~11 mm` 공중 부양)로 꽂히는 소켓 구조입니다.
   - 소켓 좌우 열 사이(`19.8 mm × 71.1 mm`) 하부 공간에 저배형 소자(`1/8W` 저항 14개 `H=1.6 mm`, `1N4148` 다이오드 `H=1.9 mm`, `100nF` 커패시터 `C3`/`C4` `H≈4.3 mm`)를 배치해 상부 여백 `5 mm` 이상을 확보했습니다.
   - 외부 접근/조작이 필요하거나 키가 큰 부품(`J1`~`J5`, `U1 MP1584`, `SW1`, `C1`/`C2` 11mm 전해, `F1`, `C5`~`C7`)은 모두 `U2` 바깥쪽에 배치했습니다.
   - *(조립 순서 권장: 소켓 하부 저항·다이오드·`C3`/`C4`를 먼저 납땜한 뒤 `U2` 암헤더 2열을 납땜하세요.)*

2. **기능 동등 MCU 핀 재배치 (펌웨어 반영 필수)**
   - ATmega128A의 하드웨어 기능(16비트 Timer3 PWM, 외부 인터럽트 `INT4`/`INT6`, 일반 GPIO)을 100% 동일하게 유지하면서 배선 직결을 위해 `PE3`~`PE7` 핀만 최적화했습니다. (ISP `PE0/PE1/PB1`, JTAG `PF4~PF7`, 고정 I²C `PD0/PD1`, 고정 UART1 `PD2/PD3`, `ADC0` `PF0`은 일체 건드리지 않음)

| 신호 | 기존 `v4` 핀 | 변경 `v4_opt` 핀 | 기능 동등성 및 개선 효과 |
| :--- | :--- | :--- | :--- |
| **`/PWM_M1`** | `PE3` (5번, `OC3A`) | **`PE5` (7번, `OC3C`)** | 동일 16비트 Timer3 PWM (`OC3C`). `PB5~PB7`에 `5.08 mm` 더 근접 (`48.6 mm` → **`29.9 mm`**) |
| **`/ECHO`** | `PE4` (6번, `INT4`) | **`PE6` (8번, `INT6`)** | 동일 외부 인터럽트 (`INT6`). `J2.3`와 수평 **`7.0 mm` 직선 연결** |
| **`/TRIG`** | `PE5` (7번, GPIO) | **`PE7` (9번, GPIO)** | 일반 디지털 출력. `J2.2`와 수평 **`7.0 mm` 직선 연결** |
| **`/IMU_INT`** | `PE6` (8번, `INT6`) | **`PE4` (6번, `INT4`)** | 동일 외부 인터럽트 (`INT4`). `B.Cu` 단일 경로로 `J5.8` 직결 |
| **`PE3` (5번)** | `/PWM_M1` | **미연결 (NC)** | `no_connect` 처리 |

3. **`+5V` 전원 및 안전 배선 최적화**
   - **`+5V` 전체 배선 길이**: 기존 `175.3 mm` → **`127.7 mm`** (약 **27% 단축**)
   - **GND 패드 근접 제거**: `SW1` → `U2` 횡단 구간이 기존에는 `GND` 핀(`U2.39`) 옆을 지나갔으나, 새 설계에서는 **양쪽 모두 미연결 핀인 `U2.37 (PF7)`과 `U2.38 (/RST)` 사이(`y = 74.49`)로만 통과**해 손납땜 시 `+5V`-`GND` 쇼트 위험을 원천 차단했습니다.
   - **전원 블록 직선 흐름 (우측 열)**: `J1 (BAT_TAP)` → `F1` → `C1` → `U1 (MP1584)` → `C2` → `SW1` → 수평 직선으로 `C3`/`U2.10`/`J2.1`/`C5` 공급 → 좌측 수직 간선(`x=132.2`)으로 `C6`/`J5`, `C7`/`J4` 공급.
   - **소신호 최단 직결**: `/ECHO`, `/TRIG`, `/SCL`, `/SDA` 모두 **`7.0 mm` 수평 직선**, `/TXD1` **`5.0 mm` 수평 직선**, `/VBAT` **`6.0 mm` 수직 직선**.

### 1-1. J5(GY-521) 180° 회전 (2026-11-23)
- 문제: GY-521 기판(15.56 × 20.26 mm)은 핀 열 한쪽에서 약 14.3 mm 뻗는데, 기존 방향은 `U2` 쪽(오른쪽)이라 모듈과 같은 높이(8.5 mm 암헤더)에서 겹침.
- 수정: `J5`를 `(139, 103.7) 0°` → `(139, 121.48) 180°`. 핀 열 x는 그대로, 핀 1(5V)이 아래, 핀 8(INT)이 위. GY-521은 부품면 위로 꽂고 본체가 왼쪽으로 감.
- 재배선: `+5V` J5.1 → C7 노드 직결(`F.Cu` 0.8), `/SDA` J5.4 → PD1 `F.Cu` 사선, `/SCL` J5.3 → PD0 `B.Cu`(x=142.5) 우회, `/IMU_INT` J5.8 → `B.Cu` y=102.43 → x=153.2 간선 → PE4. 핀 이름 실크(5V…INT) 순서 반전, J5 레퍼런스는 헤더 위로.
- 결과: DRC 오류 0·미연결 0(경고 24는 라이브러리 풋프린트 불일치), 거버·드릴 재출력.
- 주의: GY-521 본체가 보드 왼쪽 끝(x=126)을 약 1.3 mm 벗어나고, `C6`·`C7`·+5V 간선 위에 뜸 → 디스크 커패시터는 8.5 mm 이하로 낮게 납땜.
- 후속 수정(같은 날): 회전 후 J5 5V가 HC-06용 `C7`에 붙고 `C6`(GY-521용)는 J5와 무관한 위치(135, 103.7)에 남아 있던 문제 수정.
  - `C6` → `(134.8, 120.5) 90°`(기존 C7 자리). J5.1 → C6.1 직결, 간선(x=132.2) → C6.1 사선 유지.
  - `C7` → `(130, 122.7) 90°`(J4 왼쪽, MH3 위). 간선을 x=132.2로 y=120.5까지 연장 → 사선 → C7.1 → 사선 → J4.1. 기존 C6 분기 `(132.2,100.9)-(135,103.7)`와 `C6.1-J4.1` 직선 삭제.
  - 직각 꺾임 2곳 45° 모따기: `/SCL` B.Cu `(142.5, 116.4)`, `/RXD1` F.Cu `(142.5, 113.86)`.
  - C6·C7 레퍼런스 실크 위치 조정. DRC 오류 0·미연결 0, 거버·드릴 재출력.

### 1-2. U1(MP1584) 패드 좌우 반전 (2026-11-23)
- 문제: 디바이스마트 SZH-PWSD-002 사진(뒷면 실크 IN-/IN+/OUT-/OUT+)과 비교하니 기존 풋프린트가 실물의 거울상이었음. 부품면을 위로 꽂으면 IN+↔IN-, OUT+↔OUT-가 뒤바뀌어 역접속됨.
- 실물(부품면 위, IN이 아래): 왼쪽 아래 IN-, 오른쪽 아래 IN+, 왼쪽 위 OUT-, 오른쪽 위 OUT+.
- 수정: 라이브러리 `MP1584_Module_22x17`과 보드의 U1 패드 x 좌표를 반전. 패드 1(IN+) `(186.8, 107.3)`, 2(IN-) `(172.8, 107.3)`, 3(OUT+) `(186.8, 87.7)`, 4(OUT-) `(172.8, 87.7)`. 실크 `IN+`/`IN-`/`OUT+`/`OUT-` 추가.
- 재배선: `/VBAT_F` F1.2 → (186.8, 110.9) → IN+ `F.Cu` 0.8. 전압 감지선은 C1+에서 `B.Cu` 0.25로 (170.47, 107.97)을 거쳐 기존 간선에 연결. `/+5V_REG` OUT+ → x=184.5 → y=78 → C2+/SW1 간선(x=178)에 T 분기 `F.Cu` 0.8. 기존 IN+/OUT+ 쪽 트랙은 삭제(그 자리는 GND 패드).
- 결과: DRC 오류 0·미연결 0(경고는 라이브러리 풋프린트 불일치뿐), 거버·드릴 재출력.
- 남은 확인: 실물은 단자마다 구멍이 2개씩(8개)이고 풋프린트는 4개. 패드 간격(14 × 19.6 mm)은 실측 전. → 1-3에서 수정.

### 1-3. U1(MP1584) 패드 간격·구멍 수 수정 (2026-11-23)
- 근거: components101 치수 도면(IN–OUT 구멍 열 18.542, 같은 쪽 바깥 구멍 13.208, 안쪽 8.128 → 쌍 피치 2.54), GitHub 커뮤니티 풋프린트 2개(muhshaniv46 18.5/13.265, kotakomputer 약 18.9/13.4), 디바이스마트 사진 분석(약 19.0/13.5). 기존 19.6 × 14.0은 패드마다 x 0.53·y 0.4 mm 어긋나 핀이 들어가지 않음.
- 수정: 라이브러리 `MP1584_Module_22x17`과 보드 U1을 8패드로 변경. 로컬 좌표 x ±6.604(바깥)·±4.064(안쪽), y ±9.271. 원형 1.7 mm(패드 1은 사각), 드릴 1.0. 반전 방향 유지(IN+ 오른쪽 아래, OUT+ 오른쪽 위).
- 재배선: `/VBAT_F` F1 → (186.404, 111.296) → IN+ 바깥 (186.404, 106.771), IN+ 두 구멍 사이 0.8 브리지. `/+5V_REG` OUT+ 두 구멍 사이 0.8 브리지, x=184.5 간선을 y=88.229까지 연장(기존 사선 삭제). GND 패드 4개는 존 연결. IN±/OUT± 실크를 모듈 외곽 안쪽(y=104.6 / 90.4) 쌍 중앙으로 이동.
- 결과: DRC 오류 0·미연결 0(경고 24, 회로도 패리티 경고 35는 수정 전과 동일 — Description 필드·마운팅 홀), 존 재충전, 거버·드릴 재출력.
- 남은 확인: 받은 모듈을 캘리퍼로 재서 18.54 × 13.21 확인. 3D 모델(`MP1584_Module.wrl`)은 미갱신.
