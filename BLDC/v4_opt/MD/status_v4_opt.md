### 전압 호환
| 모듈 | 전원 | 신호 | 판단 |
|---|---|---|---|
| HC-06 | 3.6–6V 입력(내부 3.3V 레귤레이터) → 5V 사용 가능 | RX는 분압으로 보호, TX 3.3V → RXD1 | 문제없음 |
| GY-521 | 3–5V 입력(내부 3.3V 레귤레이터) → 5V 사용 가능 | INT 3.3V → PE4 | 문제없음 (I²C는 아래 「문제점」) |
| HC-SR04 | 5V | 5V | 문제없음 |
- ATmega128 일반 I/O 입력 HIGH 최소 0.6·VCC = 3.0V(데이터시트 p318) → 3.3V 신호는 여유 0.3V로 동작
- 로직 전류 합계 약 100mA 안팎 → MP1584(3A)·폴리퓨즈(0.5A) 여유 충분

## 문제점

| 항목 | 내용 | 영향 | 대응 |
|---|---|---|---|
| I²C 전압 여유 없음 | TWI 입력 HIGH 최소 0.7·VCC = 3.5V(데이터시트 p322). GY-521 풀업이 3.3V면 기준 미달 | 통신 불안정 가능(파손 위험 없음). 흔히 동작함 | PCB 수정 없음. 불안정하면 PD0/PD1 내부 풀업 켜기(약 3.5V로 경계) 또는 외부 레벨 변환 모듈 |
| HC-06 수직 장착 | ㄱ자 핀이라 J4에 꽂으면 수직으로 섬. 높이 약 45mm, 안테나는 위쪽 끝, GY-521과 약 3mm(추정) | 프레임 상판·덮개와 간섭 가능 | 프레임 선정 때 높이 반영 |
| HC-06 역삽입 | 반대로 꽂으면 VCC↔RXD 바뀜. 실크에 방향 표시 없음 | 모듈 손상 | 글자 면이 보드 바깥(+y)을 보게 꽂음. 주문 전 방향 실크 추가 검토 |
| J1 극성 키 없음 | 실크 +/−만 있음, 역접속 방지 회로 없음 | MP1584 손상 가능 | 선 색 확인 후 납땜 고정. 역접속 방지는 미검토 |
| GY-521 보드 밖 돌출 | 보드 왼쪽 끝을 약 1.3–1.7mm 벗어남, C6·C7 위에 뜸 | 프레임 간섭 가능 | C6·C7은 8.5mm 이하로 눕혀 납땜. 일자 헤더를 긴 쪽이 아래로 |
| HC-SR04 직결 불가 | J2에 꽂으면 센서(약 45×20mm)가 J3·ESC 케이블과 부딪히고 아래를 보지 않음 | 장착 불가 | 짧은 전선으로 기체 아래 중앙에 장착 |
| +5V 병목 브리지 | 0.3mm 트랙이 PF7·/RST 패드 사이를 지남 | 납땜 브리지 시 단락 | 오른쪽 헤더 납땜 후 확인 |
| SW1 OFF 역류 | VBAT_SENSE → D1 → +5V로 0.5mA 미만 | +5V가 수 V로 보일 수 있음(동작 영향 없음) | 없음 |
| 90° 꺾임 6곳 | /VBAT_F·/PWM_M1·/HC06_RX·/IMU_INT·+5V 일부 | 규칙만 어긋남, 제조·동작 영향 없음 | 선택 |
| 3D 모델 | MP1584·GY-521 wrl이 변경 전 모양(GY-521은 뷰어에서 U2 쪽으로 그려짐) | 렌더 이미지만 틀림 | 선택 |

## 해결해야 할 것

### 1. 주문 전 필수 (틀리면 PCB 재제작)

- [ ] **프레임 선정** — 장착홀 57×73mm(M2)과 HC-06 높이 약 45mm가 들어가는지
