## Claude가 확인한 지적
- **+5V 0.3mm 구간** `(171, 74.49)–(167.2, 74.49)` F.Cu: 파일에서 확인. U2.37(PF7)·U2.38(/RST) 패드(Ø1.7, 2.54 피치) 사이 틈이 0.84mm라 0.8mm 트랙은 들어가지 않음 → 의도된 병목. 길이 3.8mm, 로직 전류 0.2A 미만이라 전압 강하 무시. 오른쪽 헤더 납땜 후 PF7·/RST와 브리지 여부만 확인
- **남은 90° 꺾임**: +5V F.Cu `(176, 75.6)` 확인. 두 리뷰가 공통으로 든 곳은 /VBAT_F B.Cu `(166, 73)`·`(166, 104.97)`·`(170.47, 104.97)`, /PWM_M1 B.Cu `(148.2, 70.68)`, /HC06_RX B.Cu `(158.62, 125.29)`, /IMU_INT B.Cu. 제조·동작 영향 없음, 규칙(45° 모따기)만 어긋남

## 문제가 아니었던 것
- 핀 할당 전부 CLAUDE.md와 일치(ISP PE0/PE1/PB1, JTAG PF4–PF7, PE3 미연결)
- D1 방향(캐소드 +5V), C1·C2 극성, 분압 12.6V→4.2V, TXD1 분압 5V→3.33V
- 바이패스: C3이 VCC에서 4.5mm, C6이 J5.1 옆, C7이 J4.1 옆으로 분리됨
- 모듈 아래 소자 높이: 저항·D1 2mm 이하, C3·C4 4–5mm → 8.5mm 헤더 기준 여유 3mm 이상(리드를 세우지 말 것)
- GY-521 3D 모델(`GY-521_MPU6050.wrl`)은 180° 회전 후 U2 쪽으로 그려지지만 실물 방향과 반대인 모델 문제. 뷰어 겹침을 보고 J5를 다시 돌리지 않음

## 조립·운용 시 주의
- 납땜 순서: U2 사이 저항 14개·D1·C3·C4 → U2 8.5mm 암헤더 2줄 → 나머지
- GY-521 본체 아래 C6·C7은 8.5mm 이하로 눕혀 납땜
- J2에 HC-SR04를 직결하면 센서 기판(약 45×20mm)이 J3·ESC 케이블과 부딪히고 방향도 아래를 보지 않음 → 짧은 전선으로 기체 아래에 장착
- HC-06 본체·안테나는 보드 아래 가장자리 밖으로(GY-521과 약 5mm)
- J1은 극성 키 없음(실크 +/−만). 배터리 탭 선 색을 확인하고 납땜 고정 권장
- U1은 MCU·센서 꽂기 전에 단독으로 5.0V 조정(5.2V 넘지 않게)
- SW1 ON/OFF 실크는 추정 → 첫 시험 전 멀티미터 확인
- SW1 OFF에서도 VBAT_SENSE → D1 → +5V로 0.5mA 미만 역류, +5V가 수 V로 보일 수 있음(동작 영향 없음)
- I²C는 GY-521 쪽 3.3V 풀업. PD0/PD1 내부 풀업은 켜지 않음. ATmega128 TWI 입력 VIH 최소는 0.7·VCC(5V에서 3.5V)라 3.3V 풀업은 규격상 여유가 없음(Claude 추가, 데이터시트 TWI 특성표로 재확인 필요). GY-521+5V AVR 조합은 흔히 동작하지만, 통신이 불안정하면 레벨 변환을 검토
- 유선 백업 시 HC-06 제거(RXD1 공용)
- 0.8mm 판: 모듈 뽑을 때 보드를 받치고, M2 나사는 세게 조이지 않음
