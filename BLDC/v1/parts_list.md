## 4. 아직 정하지 않은 것

| 항목 | 상태 |
|---|---|
| 플럭스, 핀셋, 솔더윅 | SMD 납땜에 필요. 대여 공구함에 있는지 미확인 |
| 로직 배선 24~26AWG | 실험실 여분 확인. 디바이스마트 26AWG는 60m 키트(22,000원)라 소량용으로 맞지 않음 |
| J1(로직 전원) 커넥터·케이블 | 회로도는 임시로 2.54mm 2핀 헤더 |
| J2(HC-SR04)·J4(HC-06) 연결 케이블 | PCB 쪽이 소켓이므로 모듈 핀과 맞는 4선 케이블 필요 |
| J3(ESC 신호) 연결 케이블 | PCB 쪽이 5핀 헤더. ESC 신호선 끝단 확인 필요 |
| M2 나사·스페이서 | PCB M2 구멍 4개용. 프레임 확정 후 길이 결정 |
| 여분 프로펠러 | 총 8개 권장. 구매 수량 확인 후 결정 |
| 프로펠러 가드 | 미결정 |

## 주문 전 실측·확인

- MP1584(VLT-VC042) 패드 위치, SS-12D02 핀 간격, GY-521 헤더 위치, HC-06 핀 순서: 현재 PCB 풋프린트는 동종 제품 치수를 기준으로 한 값이라 실물과 다를 수 있습니다.
- 3216 MLCC의 전압 정격: 품목을 고르지 않았습니다. C3~C7은 5V 이하 회로에 들어갑니다.
- 2012 저항의 정격 전력: 1/8W는 일반값이며 구매 품목 표기로 확인하지 않았습니다.
- 모터·ESC·프로펠러의 실제 모델: 구매 내역을 보지 못했습니다.
