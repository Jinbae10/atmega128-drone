## 회로도에서 고친 것

| 지적 | 출처 | 조치 |
|---|---|---|
| D1 1N5819 누설 전류로 배터리 전압이 높게 읽힘 | Grok, agy | 1N4148(DO-35)로 교체. 넷 동일, ERC 오류 0 |
| F1 `MPN` 속성이 SMD 부품 `FSMD050-24-1206R`(1206, 24V)로 남아 있어, BOM을 뽑으면 잘못 주문됨 | Grok | `FRT050-33F`로 수정. ERC 오류 0 |

| 지적 | 출처 | 확인 결과 |
|---|---|---|
| J2(HC-SR04) 핀 순서가 표준과 다를 수 있음(PDF를 눈으로 보고 추정) | Grok | 넷리스트상 1=+5V, 2=TRIG, 3=ECHO, 4=GND로 **표준과 같음**. agy도 정상으로 판단 |

## 결정이 필요한 것

| 항목 | 내용 | 두 리뷰 의견 |
|---|---|---|
| J1 극성 | 극성 없는 2핀 헤더라 거꾸로 꽂으면 C1·MP1584가 파손됨 | 극성 커넥터(JST-XH 등) 또는 직접 납땜 + 실크 `+`/`-` 크게 표시 |

## 운용 시 주의 (회로 변경 없음)

- 스위치를 꺼도 배터리 쪽 전류가 계속 흐르고, D1을 통해 +5V로 소량 역류합니다 → 비행 후 배터리 분리
- MP1584는 가변 출력 → 모듈·센서를 꽂기 전에 무부하 5.0V 측정 필수
- 5V가 단락돼도 폴리퓨즈는 느리게(초 단위) 동작해서 SW1이 먼저 상할 수 있음
- ESC 헤더를 뒤집어 꽂으면 MCU 핀 전류가 약 35~40mA(절대 최대 근처) → 실크로 1번 핀(흰색 선) 표시, 네 개 모두 같은 방향
- 펌웨어: 타이머3은 OC3A(PE3)만 켜기(PE4/PE5는 초음파 센서). TWI 사용 시 PD0/PD1 내부 풀업 끄기(GY-521이 3.3V 풀업)
- 3.3V 출력(HC-06 TX, GY-521)과 ATmega VIH 3.0V 사이 여유가 0.3V뿐 → 선을 짧게, 5V를 5.2V 이상으로 올리지 않기
- 저항 ±5% 때문에 분압이 약 3.9~4.5V로 벌어질 수 있음 → 멀티미터 실측값으로 펌웨어 보정 계수 설정

## v4 PCB 배치·배선 (2026-11-17, 재배치판)

1차판(Freerouting 자동 배선)은 kicad·EMC 분석에서 전원부가 5V 사용처 반대편에 있고, GND를 트랙으로 378mm 중복 배선하며, 뒷면 신호가 GND 플레인을 끊는 문제가 나와 전부 다시 배치하고 수동 배선했습니다.

- 보드 93.5×84mm(1차 96×100mm), x 100~193.5, y 50~134, 2층, M2 구멍 4개(모서리에서 3.5mm). 모듈 위쪽(JTAG·USART 케이블 쪽)은 보드 끝이라 부품 없음
- **전원부(오른쪽 한 줄에 모음)**: 아래에서 위로 J1(배터리, 실크 `+`/`-`) → F1 → C1 → MP1584(U1) → C2 → SW1. 배터리 분압·필터·클램프(R1·R14·R2·R3·C4·D1)는 PF0(우 1번) 바로 옆 오른쪽 위
- +5V 경로: SW1 → 모듈 오른쪽 핀 39·40 사이(빈 핀) → 모듈 안쪽(소켓 사이) 세로 간선 → 모듈 VCC(좌 10번)·C3. 같은 간선에서 HC-SR04(C3 옆), GY-521(좌 19·20번 핀 사이), HC-06(모듈 아래쪽), D1 클램프(모듈 위쪽)로 분기. 0.8mm, 핀 사이를 지나는 곳과 GY-521 분기만 0.3mm
- **왼쪽 신호부** (2026-11-18 재배치): ESC 헤더 J3(1×5, 1=M1 … 5=GND)는 왼쪽 가장자리. M1=PE3, M2~M4=PB5~PB7로 재배정해 J3 순서와 MCU 핀 순서가 같음. 모터마다 한 줄에 J3 → 100Ω 직렬 → 10k 풀다운(5.08mm 간격 4줄), PWM은 풀다운 GND 패드 아래로 우회해 MCU로 직진. +5V는 모듈 소켓 사이 x=150 간선(J5·J4)과 x=165.5 간선(D1)으로 단축. HC-SR04(J2)는 PE4/PE5와 같은 높이, GY-521(J5)은 PD0/PD1과 같은 높이(SCL·SDA 8mm 직선), HC-06(J4)은 아래 가장자리(본체·안테나가 보드 밖으로 나가 안테나 아래 GND 없음)
- **배선**: 신호는 모두 앞면. 뒷면은 GND 플레인이며, 유일한 뒷면 트랙은 IMU_INT(PE6 → 모듈 아래 → J5 8번) 한 개. GND 트랙 0, 앞·뒷면 GND 채움 + 스티칭 비아 146개(6mm 격자)
- 넷클래스: 신호 0.25mm, 전원(+5V, /+5V_REG, /VBAT, /VBAT_F, GND) 0.8mm. 전원 간격은 0.3 → 0.25mm로 낮춤(5V·12.6V라 충분)
- 결과(1차판 → 재배치판): 총 배선 길이 1,203 → 616mm, GND 트랙 378 → 0mm, 뒷면 신호 약 380mm → IMU_INT 62mm, ESC 직렬저항~헤더 20.5 → 4mm, SCL·SDA 19~24 → 8mm, TRIG·ECHO 16 → 7mm
- DRC(kicad-cli, 회로도 대조): **오류 0, 미연결 0.** 남은 경고: 장착 구멍 풋프린트 라이브러리 경고, 필드 Description 불일치, U2 `/PEN`·`/RST` 핀 이름 `/` 표기 경고, J2 4번(GND) 앞면 써멀 스포크 1개(`starved_thermal`, 뒷면 플레인으로 연결되어 있어 경고로 낮춤)
- kicad 스킬 분석: PCB 오류 0, 교차 분석 0. EMC GP-001(기준면 틈)은 짧은 신호선 양 끝의 스루홀 패드 주변 플레인 여유 공간 때문에 나오는 휴리스틱 결과로, 뒷면 렌더 확인 결과 플레인은 IMU_INT 아래 한 곳 말고는 끊기지 않음
- 남은 일: **실측(모듈 줄 간격, MP1584 패드, SS-12D02 핀 간격, ESC 핀 순서, 커패시터 리드 간격) 반영 전 거버 출력 금지.** ESC 핀 순서가 바뀌면 J3/J6/J7/J8 패드 순서와 실크만 수정. SW1의 ON 방향 실크는 실물 확인 후 추가
