# v4 회로도 설명 (AI·발표용)

- 기준: `BLDC/v4/drone_v4.kicad_sch` 넷리스트 (2026-11-18 추출), 그림은 `BLDC/v4/drone_v4_schematic.pdf`
- 이 문서는 회로도 PDF와 같이 읽는다. 연결은 그림보다 아래 「넷 연결표」가 정확하다
- PCB `drone_v4.kicad_pcb`에도 이 회로도가 반영되어 있다 (2026-11-18, 93.6×84.1mm, DRC 오류 0, 실측 반영 전)

## 1. 무엇을 하는 보드인가

ATmega128A 대여 모듈(AT128A-70B, U2)을 암헤더로 꽂는 **캐리어 PCB**. 쿼드콥터에서 다음을 담당한다.

- 3S LiPo(9.9~12.6V)에서 로직용 5V를 만든다 (모터 전류는 이 PCB를 지나지 않음: 배터리 → XT60 → 분배 보드 → ESC)
- MCU의 PWM 4개를 ESC 4개로 보낸다
- 센서·통신 모듈 연결: MPU-6050(GY-521, I²C), HC-SR04(초음파 고도), HC-06(블루투스 UART)
- 배터리 전압을 ADC로 측정한다

2층, 0.8mm, 전부 스루홀(손납땜). 부품 31개.

## 2. 블록별 설명

### 2.1 전원 (J1 → F1 → U1 → SW1 → +5V)

```
J1(BAT_TAP) ─VBAT─ F1 ─VBAT_F─┬─ C1 100µF → GND
                              ├─ U1 MP1584 IN+ ─ OUT+ ─+5V_REG─┬─ C2 100µF → GND
                              │                                └─ SW1 ─ +5V
                              └─ R1 → (전압 감지, 2.2절)
```

| 부품 | 값 | 역할 |
|---|---|---|
| J1 | 2핀 헤더 | 배터리 입력 (1=VBAT, 2=GND). 커넥터 종류·극성 미정 |
| F1 | FRT050-33F (폴리퓨즈 0.5A, 33V) | 로직 쪽 단락 시 전류 차단, 식으면 복귀 |
| C1 | 100µF 35V 전해 | MP1584 입력 벌크. 배터리 선 인덕턴스로 생기는 입력 출렁임 흡수 |
| U1 | MP1584 모듈 (SZH-PWSD-002) | 벅 컨버터 12.6V → 5V. 출력은 가변이라 **연결 전 멀티미터로 5.0V 조정 필수** |
| C2 | 100µF 35V 전해 | 5V 출력 리플·부하 변동 완화 |
| SW1 | SS-12D02 슬라이드 스위치 | +5V_REG(2번, 공통)를 +5V(1번)로 연결/차단. 3번 미사용. 정격 약 0.3A라 로직 전류만 통과 |

- 퓨즈 뒤에서 세 갈래(C1, U1, R1)로 나뉜다
- SW1은 5V만 끊는다. **J1이 꽂혀 있으면 F1·C1·MP1584·분압 저항에는 계속 전류가 흐르므로 보관 시 J1을 뽑는다** (분압만 약 0.42mA)
- 모듈에는 레귤레이터가 없다. 모듈 VCC(10번), 외부전원 커넥터, USART 커넥터 5V, JTAG VREF가 모두 같은 레일이다. 이 보드는 +5V를 **VCC 핀으로 넣어** 모듈에 전원을 준다. 그래서 모듈의 외부전원 커넥터와 AR-UART2USB 적색 5V는 연결하지 않는다

### 2.2 배터리 전압 감지 (→ PF0/ADC0)

```
VBAT_F ─ R1 10k ─ R14 10k ─VBAT_DIV─┬─ R2 10k → GND
                                    └─ R3 1k ─VBAT_SENSE─┬─ U2 PF0 (30번)
                                                          ├─ C4 100nF → GND
                                                          └─ D1 1N4148 (A) → (K) +5V
```

- **왜 분압**: ADC 입력은 0~5V(AVCC 기준)까지만 허용된다. 20k/10k로 1/3: 12.6V → 4.2V, 9.9V → 3.3V
- **왜 20k가 10k 2개**: 20k 단품을 사지 않고 이미 사는 10k를 재사용
- **R3 1k + D1**: 분압 출력이 5V를 넘으면(배터리 오접속 등) D1이 +5V로 흘려 PF0을 약 5.6V 이하로 묶는다. R3은 그때 흐르는 전류를 제한. 1N5819는 누설 전류로 값이 틀어져 1N4148 사용
- **C4**: 노이즈 필터 겸 ADC 샘플링 커패시터 충전용. 시정수 약 (6.67k+1k)×100nF ≈ 0.77ms
- **왜 PF0**: ADC는 PF0~PF7뿐이고, PF4~PF7은 JTAG(퓨즈 변경 금지)라 PF0~PF3만 가능. 그중 ADC0, 헤더 우 1번이라 배치가 편함
- **왜 측정**: LiPo 과방전 방지(셀당 약 3.3V 이하 금지), 전압 저하 시 착륙·페일세이프, 텔레메트리

### 2.3 ESC 신호 (OC1A/B/C, OC3A → J3)

| MCU 핀 | 넷 | 풀다운 | 직렬 | J3 핀 |
|---|---|---|---|---|
| PE3 / OC3A (5번) | PWM_M1 → ESC_M1 | R7 10k | R11 100Ω | 1 |
| PB5 / OC1A (16번) | PWM_M2 → ESC_M2 | R4 10k | R8 100Ω | 2 |
| PB6 / OC1B (17번) | PWM_M3 → ESC_M3 | R5 10k | R9 100Ω | 3 |
| PB7 / OC1C (18번) | PWM_M4 → ESC_M4 | R6 10k | R10 100Ω | 4 |
| — | GND | | | 5 |

- 1~2ms 표준 서보 PWM (BLHeli_S 자동 감지). Timer1 채널 3개 + Timer3 채널 1개
- **10k 풀다운(MCU 쪽)**: 리셋·프로그래밍 중 핀이 입력(하이 임피던스)이 되면 ESC 입력이 떠서 오동작할 수 있다. LOW로 고정
- **100Ω 직렬**: 긴 신호선의 링잉 감쇠, 단락 시 MCU 핀 보호
- ESC 신호 GND는 J3 5번으로 공통. ESC 케이블(3칸 서보 하우징, 가운데 빈 칸)은 1×5에 맞게 개조 필요(방법 미정)
- 펌웨어: 부팅 직후 1000µs 유지(아밍). 최대 스로틀로 부팅하면 ESC가 캘리브레이션 모드로 들어간다

### 2.4 센서·통신

| 커넥터 | 핀 | 연결 | 비고 |
|---|---|---|---|
| J2 HC-SR04 (1×4 소켓) | 1 +5V, 2 TRIG, 3 ECHO, 4 GND | TRIG=PE5(7번), ECHO=PE4/INT4(6번) | ECHO 펄스 폭을 외부 인터럽트로 측정 |
| J5 GY-521 (1×8 소켓) | 1 +5V, 2 GND, 3 SCL, 4 SDA, 5~7 미연결(XDA·XCL·AD0), 8 INT | SCL=PD0(22번), SDA=PD1(23번), INT=PE6/INT6(8번) | 5V 입력 가능(보드 내 3.3V LDO), 보드 내장 I²C 풀업 사용. AD0 미연결 → 주소 0x68. **핀 순서 실물 확인 필요** |
| J4 HC-06 (1×4 소켓) | 1 +5V, 2 GND, 3 TXD, 4 RXD | HC-06 TXD → RXD1=PD2(24번) 직결. TXD1=PD3(25번) → R12 1k → HC06_RX → R13 2k → GND | HC-06 RX는 3.3V → 5V×2/3 = 3.33V로 분압. **핀 순서 실물 확인 필요** |

- USART1(PD2/PD3)은 모듈 USART 커넥터와 공용. 유선 백업(AR-UART2USB)을 쓸 때는 HC-06을 뺀다(RX 충돌)

### 2.5 바이패스 커패시터 (100nF)

C3 → U2 모듈 VCC(10번), C5 → J2, C6 → J5, C7 → J4. 회로도에서도 각 부품 전원핀 옆에 연결선으로 그린다(2026-11-18).
+5V는 PCB 배선 순서대로 J5(GY-521) 1번 → C6 → J4(HC-06) 1번 → C7로 이어지게 그렸다. +5V 심볼은 J5와 J4 사이 분기점에 하나만 둔다.

## 3. MCU 핀 사용 요약 (U2 헤더 번호)

| 번호 | 핀 | 용도 | 번호 | 핀 | 용도 |
|---|---|---|---|---|---|
| 5 | PE3 | M1 PWM (OC3A) | 22 | PD0 | SCL |
| 6 | PE4 | ECHO (INT4) | 23 | PD1 | SDA |
| 7 | PE5 | TRIG | 24 | PD2 | RXD1 |
| 8 | PE6 | IMU INT (INT6) | 25 | PD3 | TXD1 |
| 10 | VCC | +5V 입력 | 30 | PF0 | VBAT_SENSE (ADC0) |
| 16~18 | PB5~PB7 | M2~M4 PWM (OC1A/B/C) | 21, 39 | GND | GND |

사용하지 않거나 쓰면 안 되는 핀:
- PE0/PE1/PB1: ISP(PDI/PDO/SCK) → 사용 금지. USART0(PE0/PE1)도 ISP와 충돌
- PF4~PF7: JTAG
- PD2/PD3은 USART1이라 INT2/INT3 사용 불가
- PA·PC·PG0~2: 외부 버스 핀. 이 보드에서는 미사용
- /PEN, /RST: 미연결

## 5. 아직 정하지 않았거나 실측이 필요한 것

- J1 커넥터 종류·극성, 역접속 보호(현재 없음)
- MP1584 모듈 패드 위치, SS-12D02 고정 탭, 100nF 리드 간격, 모듈 좌우 핀 줄 간격(22.86mm 추정)
- GY-521·HC-06 핀 순서 실물 확인
- ESC 케이블을 1×5 헤더에 맞추는 개조 방법
