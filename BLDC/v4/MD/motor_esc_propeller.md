## 확인할 것

1. 주문 내역에서 산 옵션 확인 → 프롭 포함 세트였으면 프롭 크기 확인 후 추가 구매 여부 결정
2. 검정·은색 너트가 각각 어느 나사 방향인지 (모터 몸체 표시 확인). 프롭 방향과 너트 방향이 맞아야 비행 중 풀리지 않음
3. ESC 일반 PWM 입력 시험
4. 와트미터로 모터 1개 풀스로틀 전류 측정 → **16A(20A의 80%) 이하**면 사용
