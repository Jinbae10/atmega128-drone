# DC v3 계획 — 1020 모터 + 2S 배터리

> 작성일: 2026-10-20 · 상태: 계획 (회로도·PCB 미착수)
> 변경 이유: 8520 + 1S 조합의 **추력 부족**

---

## 1. 확정 사항

| 항목 | v1/v2 | v3 |
|---|---|---|
| 모터 | 8520 코어리스 (3.7V) | **1020 코어리스 7.4V ×4 (CW 2 + CCW 2), 54,000RPM, 축 1.2mm** |
| 배터리 | 1S LiPo 3.7V (3.0~4.2V) | **2S LiPo 7.4V (6.0~8.4V)** |
| PWM 듀티 | 0~100% | 0~100% (모터가 7.4V 정격이라 상한 없음) |

- 구매처: [알리 1020 7.4V 2개입](https://ko.aliexpress.com/item/1005013146545727.html) — ₩7,470/2개, 5개 이상 개당 ₩5,240
- **4개 사용 — CW 2개 + CCW 2개** (대각선끼리 같은 방향). 여분 모터는 별도 구매 권장

---

## 2. 바뀌는 것

### 2.1 전원 (필수 변경)
| 항목 | v1/v2 | v3 |
|---|---|---|
| 5V 레귤레이터 | MT3608 **승압** 모듈 | **강압** — MP1584EN 미니 모듈 권장 (입력 최대 28V, 약 2g). 대안은 AMS1117-5.0 LDO (배터리가 6.0V까지 떨어지면 5V 유지가 빠듯함) |
| 배터리 커넥터 | JST PH2.0 (정격 약 2A) | 실물 배터리에 맞춤. 모터 4개 전류에 PH2.0은 부족하므로 **XT30 권장** |
| 충전기 | 1S USB 충전기 | **2S 밸런스 충전기 새로 필요** |
| VBAT 커패시터 (C1 등) | 전압 정격 미표기 | **16V 이상** |

- ⚠️ **MT3608은 반드시 뺀다.** 입력(7.4V)이 출력(5V)보다 높으면 입력 전압이 그대로 넘어가 모듈에 7~8V가 들어간다 → MCU 손상
- MP1584도 받은 상태로는 5V가 아니다 → 연결 전 멀티미터로 **5.0V 조정** (MT3608 때와 같은 절차)

### 2.2 모터 구동부
| 항목 | v1/v2 | v3 |
|---|---|---|
| MOSFET | SI2302 (20V, 2.5~3A) | **AO3400** (30V, 5.7A) 권장 — SOT-23 핀 배치가 같아 풋프린트 그대로 |
| 환류 다이오드 | SS14 / 1N5819 (40V 1A) | 전류 여유를 두려면 SMD **SS34**(같은 SMA, 3A) / THT 1N5822(DO-201, 풋프린트 바뀜) |
| 게이트 | 100Ω 직렬 + 10kΩ 풀다운 | 그대로 |
| 모터 루프 선폭 | 1.0mm | 모터 전류를 실측한 뒤 재계산 |

### 2.3 배터리 전압 측정 (ADC)
- 10k/10k 분압은 **그대로** 쓴다: 8.4V → 4.2V로, 5V 기준 ADC 범위 안에 들어간다
- 펌웨어만 바꾼다: 환산식, 저전압 기준을 셀당 3.3V × 2 = **6.6V**로. 셀별 전압은 측정할 수 없다

### 2.4 기구·무게
| 항목 | 변경 |
|---|---|
| 모터 홀더 | 8.5mm → **10mm**. 프레임이나 홀더 STL을 다시 고름 |
| 프로펠러 | 구멍 **1.2mm**, 65~75mm CW/CCW 세트를 따로 구매 (8520 프로펠러는 축이 맞지 않음) |
| 프레임 | 프로펠러 크기에 맞춰 모터 간격 다시 확인 |
| 무게 예산 | 1020 모터와 2S 배터리 모두 더 무거움 → 추력을 실측한 뒤 "추력 ≥ 무게 × 2"로 다시 계산 (75g 제한은 폐기 예정) |

### 2.5 펌웨어
- 배터리 전압 환산·저전압 기준 (2.3)
- 모터가 바뀌므로 PID 게인 재튜닝

### 2.6 그대로인 것
MCU 모듈, 핀 할당 전부 (PWM PB5/PB6/PB7/PE3, USART1, I²C, ADC0), HC-06 분압, 센서, 5V 이하의 회로.

## 3. 모터 도착 후 실측

| # | 측정 | 방법 | 결정되는 것 |
|---|---|---|---|
| 1 | 전류 (프로펠러 장착, 7.4V, 최대 출력) | 멀티미터 10A 단자 / 전원공급기 전류 표시 | MOSFET·다이오드 등급, 모터 루프 선폭, 배터리 C-rate |
| 2 | 추력 | 모터를 저울 위에 거꾸로 고정하고 최대 출력 | 무게 예산 |
| 3 | 모터 1개 무게 | 저울 | 무게 예산 |
| 4 | 기동 전류 | 측정이 어려우면 정격 전류의 2배로 가정 | 커패시터, 배터리 커넥터 |

## 4. 결정 필요

1. **기반 보드**: v1(SMD, 가벼움) 권장 / v2(THT, 무거움)
2. **5V 레귤레이터**: MP1584 모듈(권장) / AMS1117 LDO
3. **배터리 모델**: 용량·무게·커넥터 종류 → J1 풋프린트
4. **2S 충전기 모델**

---

## 5. 작업 순서

1. 4번 결정 → `DC/v1/`(또는 v2)을 `DC/v3/`로 복사하고, 파일명과 스크립트의 `LIB`/`OUT` 경로를 v3로 바꿈
2. `gen_fp.py`: 강압 모듈 풋프린트 (MP1584 패드 배치는 실물로 확인), 배터리 커넥터
3. `gen_sch.py`: U2 강압 모듈, Q1–Q4 AO3400, (선택) D1–D4 SS34, C1 정격, J1 커넥터, 회로도 주석("1S"/"MT3608" 문구)
4. `gen_pcb.py`: 모듈 위치·크기, 모터 루프 선폭 (실측 후)
5. DRC → 거버 출력 (`DC/v3/gerber/`)
6. 문서 수정: `drone_term_project.md` (확정 사항, 3장 비교표, 부품표·예산, 6.1 전원도, 무게, 리스크), `CLAUDE.md` 하드웨어 제약, `hw_block_diagram.svg`, 발표 자료·대본
